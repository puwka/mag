# Очистка фото товаров от брендинга ВИТЕКС

Автоматический пайплайн: скачивание → удаление логотипа/подписей → проверка.

## Структура

```
original/          # исходники (не перезаписываются)
clean/             # очищенные версии
clean/verification-report.json
```

## Требования

- Python 3.10+
- OpenCV, NumPy (см. `scripts/requirements-image-clean.txt`)

```bash
pip install -r scripts/requirements-image-clean.txt
```

## Запуск

```bash
# 1. Скачать все фото товаров из Supabase в original/
npm run images:download

# 2. Удалить брендинг → clean/
npm run images:clean

# 3. Проверка результата
npm run images:verify

# Всё сразу
npm run images:pipeline
```

Один файл:

```bash
python scripts/clean-product-images.py --file original/foo.jpg --save-mask
```

## Что удаляется

| Зона | Элемент |
|------|---------|
| Верхний правый угол | «Фабрика ВИТЕКС», круглая эмблема |
| Верхний левый угол | красная стрелка, «N нитка» |
| Нижний правый угол | синий бейдж «Упаковка N пар» |

**Не трогается:** красная обметка манжеты, текстура перчатки, ПВХ-точки, пропорции.

## Метод

1. Построение маски по цвету и положению (только углы кадра).
2. Content-aware inpainting (OpenCV Navier-Stokes + Telea).
3. Восстановление белого фона по медиане краёв.
4. Второй проход по остаткам брендинга.
5. Автопроверка: нет красного/синего/тёмного текста в зонах брендинга.

Фото **без** стандартного брендинга (тёмный фон, ткани) копируются в `clean/` без изменений.

## Ограничения

- Оптимизировано под шаблон vitex37.ru (600×600, белый фон).
- Inpainting у кончика красной стрелки на перчатке может оставить лёгкий след — для идеального результата отдельные кадры можно доработать вручную.
- Для максимального качества можно подключить LaMa (`simple-lama-inpainting`) — требует PyTorch.

## После очистки

Загрузите файлы из `clean/` в Supabase Storage (bucket `products`) и обновите `product_images.storage_path` в админке или через скрипт.
